Tree — multi-level expandable list with selection/checkbox support. Only required: items. TreeItem = { key: React.Key, title?: ReactNode|((data)=>ReactNode), className?, style?, disabled?, icon?, children?: TreeItem[], contentRight? }. checkable enables checkboxes; multiple for multi-select. draggable + onDrop/allowDrop for drag'n'drop reordering (onDrop gives dropKey/dragKey/dropPosition, you mutate the items array yourself). loadData for async lazy-loading children (returns a Promise, resolves when done).
LIVE EDITOR
function App() { return <Tree items={treeData} defaultExpandAll checkable multiple />; }
