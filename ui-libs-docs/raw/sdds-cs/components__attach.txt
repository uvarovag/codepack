Attach — компонент, позволяющий прикрепить локальный файл.

LIVE EDITOR (basic)
function App() {
return <Attach text="Загрузить файл" />;
}

Внешний вид: view, size, buttonType. Расположение: flow = "auto"(default) | "horizontal" | "vertical" — расположение прикреплённого файла относительно кнопки. Подсказка: helperText + helperTextView. Несколько файлов: multiple. Фильтр форматов: acceptedFileFormats (как HTML accept). Контролируемый режим: files + onChange (e.target.files) + onClear(fileInfo.file). ref форвардится на <input type="file">, поэтому файлы попадают в FormData при сабмите формы (name на Attach).

LIVE EDITOR (controlled)
function App() {
const [files, setFiles] = useState([]);
return (
<Attach flow="horizontal" files={files} onChange={(e) => setFiles(Array.from(e.target.files || []))} onClear={(fileInfo) => setFiles((prev) => prev.filter((f) => f !== fileInfo.file))} />
);
}
