Tour — spotlight product-tour overlay, highlights target elements step by step. steps: TourStep[] = { target: string(CSS selector)|RefObject|HTMLElement, placement?, highlightOffset?, highlightBorderRadius?, title?, description? }. renderStep* is required: (current, length, last, step, goToStep) => ReactNode — you build the step card yourself (or use the bundled TourCard component for a ready-made card with image/pagination/buttons). Controlled via open/current/onChange/onClose (or defaultOpen/defaultCurrent uncontrolled). withOverlay dims background; renderHighlight lets you replace the default spotlight box-shadow with custom markup, given {left, top, width, height, borderRadius}.
LIVE EDITOR
function App() {
const ref1 = useRef(null); const ref2 = useRef(null);
const [open, setOpen] = useState(false); const [current, setCurrent] = useState(0);
const steps = [{ target: ref1, title: 'Шаг 1', description: '...' }, { target: ref2, title: 'Шаг 2', description: '...', placement: 'top' }];
const renderStep = (cur, length, last, step, goToStep) => (
<div>
{step.title}<br/>{step.description}
{cur > 0 && <Button onClick={() => goToStep(cur - 1)}>Назад</Button>}
{last ? <Button onClick={() => setOpen(false)}>Закрыть</Button> : <Button onClick={() => goToStep(cur + 1)}>Далее</Button>}
</div>
);
return (
<>
<Button ref={ref1}>Элемент 1</Button><Button ref={ref2}>Элемент 2</Button>
<Button onClick={() => setOpen(true)}>Запустить тур</Button>
<Tour open={open} current={current} onChange={setCurrent} onClose={() => setOpen(false)} steps={steps} renderStep={renderStep} highlightBorderRadius="1rem" hasTail />
</>
);
}
