Modal (raw sdds-cs — cs-core also has its own Modal/MobileModal, cs-portal re-exports cs-core's Modal, shadowing this one). Requires <PopupProvider> wrapping app root. Similar to Popup but adds overlay + blocks scroll/focus. hasBody wraps children in a styled container with padding + close X. Width not set by default (fits content) — pass style={{width:...}} on Modal itself (works with hasBody too). draggable enables drag-to-move. resizable enables resize handles (same shape as Popover's resizable). isFocusTrapped=true (default) traps Tab focus inside; focusTrapSelectors for portal-rendered content outside the modal's DOM subtree.
LIVE EDITOR
function App() {
const [isOpen, setIsOpen] = useState(false);
return (
<PopupProvider>
<Button text="Open" onClick={() => setIsOpen(true)} />
<Modal opened={isOpen} onClose={() => setIsOpen(false)} placement="center" offset={[0,0]} hasBody style={{ width: '25rem' }}>
Content
</Modal>
</PopupProvider>
);
}
