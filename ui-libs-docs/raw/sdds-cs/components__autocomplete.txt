Autocomplete — поле ввода с подсказками в выпадающем списке. Расширенная версия TextField — все пропсы TextField поддерживаются. Подсказки фильтруются без учёта регистра по умолчанию, можно переопределить через filter. Формат suggestions: { label: string; contentLeft?: ReactNode; contentRight?: ReactNode }.

LIVE EDITOR
function App() {
const mockData = [{ label: 'Алексей Смирнов' }, /* ... */];
return <Autocomplete suggestions={mockData} listMaxHeight="250px" label="Label" placeholder="Placeholder" leftHelper="Введите имя Алексей" />;
}

Клавиатурная навигация соответствует W3C Combobox: Tab/Escape закрывает, Enter выбирает, Home/End/ArrowUp/ArrowDown перемещают фокус.
