Steps — step/progress indicator. items: {indicator, title, content?, status: 'active'|'inactive'|'completed', height?/width?}[]. onChange(item, index, prevIndex) fires on step click — caller updates statuses manually (uncontrolled-ish). current for external control without onChange. orientation="horizontal"(default)|"vertical" (use hasLine for a connecting line, recommended in vertical). Steps can nest (e.g. inside an Accordion) — give outer steps a height when their content has variable height.
LIVE EDITOR
function App() {
const [items, setItems] = useState([{indicator:1,title:'Шаг 1',status:'active'},{indicator:2,title:'Шаг 2',status:'inactive'}]);
const onChange = (item, index, prevIndex) => {
if (prevIndex !== undefined) items[prevIndex].status = 'completed';
items[index].status = 'active';
setItems([...items]);
};
return <Steps items={items} onChange={onChange} />;
}
