TextField — base text input. This is the props shape shared/inherited by Mask, NumberFormat, Autocomplete, Combobox, Select (textfield-like target), TextArea (partially), Range fields, etc. appearance="default"|"clear" (hasDivider for clear). hint* family = tooltip icon next to the field (independent of leftHelper/rightHelper text). titleCaption = label at top-right.
LIVE EDITOR
function App() {
const [text, setText] = useState('');
return <TextField value={text} onChange={(e) => setText(e.target.value)} label="Введите имя" contentRight={text && <IconButton size="s" view="clear" onClick={() => setText('')}><IconClose color="inherit" size="s" /></IconButton>} />;
}
