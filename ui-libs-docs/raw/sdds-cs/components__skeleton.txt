Skeleton family: LineSkeleton (single line, size = typography token like "h3"/"bodyM"), RectSkeleton (width*/height* required), TextSkeleton (lines* count, optional width). animationType="shimmer"(default)|"pulse"; animationDuration ms (0 disables). withSkeleton(Component) HOC applies skeleton look to any component via skeleton={true} prop — background replaced, text made transparent; pass aria-busy={skeleton} for a11y. animationConfig={type, duration, customGradientColor, customFadeInColor, customFadeOutColor} customizes the HOC's animation.
LIVE EDITOR
function App() { return <RectSkeleton width="12rem" height="8rem" animationType="shimmer" />; }
LIVE EDITOR (HOC)
const ButtonSkeleton = withSkeleton(Button);
function App() { return <ButtonSkeleton text="Загрузка..." skeleton aria-busy />; }
