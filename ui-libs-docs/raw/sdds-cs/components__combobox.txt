Combobox (raw sdds-cs version — cs-core also has its own Combobox, shadowed/overridden by cs-portal's export; see raw/cs-core.json "Combobox"). Only required prop: items. Item shape: { value: string, label: string, placement?: Placement (default 'bottom-start'), items?: ItemOption[] (nested submenu), disabled?, contentLeft?, contentRight?, className?, listMaxHeight? }. multiple:boolean switches single (value/defaultValue: string) vs multi (string[]). mode="radio" in single mode disallows deselect-by-reclick. Multi-mode extras: selectAllOptions, isTargetAmount, targetAmount, renderValue, chipClickArea. treeView:boolean renders nested items as a tree with highlightable search. Works with react-hook-form via {...register('name')} and native forms.

LIVE EDITOR (single, nested items)
function App() {
const [value, setValue] = useState('');
const items = [
{ value: 'north_america', label: 'Северная Америка' },
{ value: 'south_america', label: 'Южная Америка', items: [
{ value: 'brazil', label: 'Бразилия' },
{ value: 'argentina', label: 'Аргентина' },
]},
];
return <Combobox items={items} value={value} onChange={setValue} placeholder="Placeholder" label="Label" helperText="Helper text" />;
}

LIVE EDITOR (multiple, target amount)
function App() {
const [value, setValue] = useState(['brazil']);
return <Combobox multiple label="Label" placeholder="Placeholder" items={items} value={value} onChange={setValue} isTargetAmount />;
}
