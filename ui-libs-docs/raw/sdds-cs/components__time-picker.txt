TimePicker. onChange(event, formattedValues: {value?: string, timeValues:{hour?,minute?,second?}}) — use formattedValues, event arg is deprecated. columnsQuantity=2(HH:mm)|3(HH:mm:ss). hasTimeFormat shows 12h AM/PM display only — value/min/max/onChange stay 24h always. min/max as "HH:mm:ss" or Date. multiplicityMinutes/multiplicitySeconds restrict step (1,5,10,15,20,30). Keyboard: Enter opens/closes, ArrowUp/Down changes value, ArrowLeft/Right moves between columns, Tab moves to next value.
