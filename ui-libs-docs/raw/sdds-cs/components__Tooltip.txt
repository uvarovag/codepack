Tooltip (component, not the beta one) — wraps target via `target` prop, opens in given placement (or an array for auto-fallback). Meant to wrap icons from @salutejs/plasma-icons. trigger="none"|"click"|"hover" (opened=true/false for manual control). Use ViewContainer view="onDark"|"onLight" wrapper to theme it for dark/light backgrounds.
LIVE EDITOR
function App() { return <Tooltip target={<Button>Btn</Button>} text="По ховеру" placement="right" hasArrow trigger="hover" mouseEnterDelay={0} mouseLeaveDelay={300} />; }
