Chip — text and/or icon, several sizes/colors. text or children. contentLeft/contentRight for icon slots. hasClear (default true) shows a close icon; contentClearButton customizes it. view="default"|"secondary"|"accent". Gradient text via class sdds-core-text-node.
LIVE EDITOR
function App() { return <Chip text="Chip" size="s" view="accent" contentLeft={<IconDownload color="inherit" />} />; }
