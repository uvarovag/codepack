Radiobox — should be grouped inside RadioGroup (radios share `name`). label/description accept JSX; singleLine=false default (multiline).
LIVE EDITOR
function App() {
return (
<RadioGroup aria-labelledby="rg-title">
<H3 id="rg-title">Заголовок</H3>
<Radiobox name="radio-1" label="Опция 1" description="Описание 1" defaultChecked />
<Radiobox name="radio-1" label="Опция 2" />
</RadioGroup>
);
}
