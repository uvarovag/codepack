Title: DatePicker | SDDS CS
URL: https://plasma.sberdevices.ru/sdds-cs/components/datepicker/
---
DatePicker — text input + dropdown calendar. DatePickerRange — two inputs (first/second) + calendar, single or double (isDoubleCalendar). format="DD.MM.YYYY" (tokens: DD/D day, MMMM/MMM/MM/M month, YYYY/YY year, Q quarter). maskWithFormat masks input to match format. lang="ru"(default)|"en". valueError/valueSuccess/valueEdited drive validation styling. onCommitDate(value, {error,success}) fires on Enter or day pick. onChangeValue(event, value, originalDate, isoDate) fires on any change. usePortal to render calendar in a portal. min/max + includeEdgeDates bound selectable dates. dateShortcuts for preset date buttons. onChangeVisibleDate(date) — visible period changed via nav (not on day/month/year drill switch).

LIVE EDITOR (DatePicker)
function App() {
const [dateValue, setDate] = useState(new Date());
return <DatePicker onChangeValue={(_, value, originalDate, isoDate) => setDate(value)} label="Дата" format="DD.MM.YYYY" maskWithFormat lang="ru" usePortal />;
}

LIVE EDITOR (DatePickerRange, double calendar, independent fill + auto-swap)
function App() {
return <DatePickerRange isDoubleCalendar usePortal label="Период" firstPlaceholder="Дата начала" secondPlaceholder="Дата окончания" format="DD.MM.YYYY" lang="ru" />;
}
