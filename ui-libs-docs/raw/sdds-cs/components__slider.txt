Title: Slider | SDDS CS
URL: https://plasma.sberdevices.ru/sdds-cs/components/slider/
---
Slider — numeric value picker. value as number = single handle, as [number,number] = range (double). onChange fires while dragging; onChangeCommitted fires on release. orientation="horizontal"(default)|"vertical". showScale shows min/max; scaleTicks for custom tick marks (numbers or {value,label,labelAlign}). showCurrentValue / currentValueVisibility "hover"|"always". step + multipleStepSize (PageUp/PageDown, % of range).
LIVE EDITOR
function App() {
const [value, setValue] = useState(30);
return <Slider min={0} max={100} value={value} label="Громкость" onChange={setValue} onChangeCommitted={setValue} />;
}
LIVE EDITOR (range)
function App() {
const [value, setValue] = useState([10, 80]);
return <Slider min={0} max={100} value={value} label="Цена" onChange={setValue} onChangeCommitted={setValue} />;
}
