Carousel — принимает набор React-элементов, отображает горизонтальную ленту с прокруткой. Simple case: just pass children. defaultIndex sets initial slide once (uncontrolled); index+onChangeIndex for controlled mode. swipeEnabled for touch/pointer drag. controlArrowsDisabled hides built-in arrows.
LIVE EDITOR
function App() {
const items = Array(10).fill(0).map((_, i) => `Слайд ${i+1}`);
return <Carousel gap="16px">{items.map((item) => <StyledCard key={item}>{item}</StyledCard>)}</Carousel>;
}
