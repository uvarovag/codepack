Select — similar to Combobox but no free-text search by default (Combobox has search/filter built in — use it if you need search). Only required: items (same item shape as Combobox: value, label, placement?, items? nested, disabled?, contentLeft?, contentRight?, className?, listMaxHeight?). multiselect switches single(string)/multi(string[]) value. mode="radio" for single non-deselectable. target="textfield-like"(default, mimics TextField, inherits its props)|"button-like". renderValue/renderTarget/renderItem/renderSelectionIcon for customization.
LIVE EDITOR
function App() {
const [value, setValue] = useState('');
return <Select items={items} value={value} onChange={setValue} label="Single" placeholder="Placeholder" helperText="Helper text" />;
}
