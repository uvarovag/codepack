Описание​

Popover — всплывающее окно, привязанное к целевому элементу (target). Оно отображает дополнительный контент по клику, наведению или фокусу.

Компонент поддерживает настройку триггера, позиции, смещения, хвостика, задержек открытия и закрытия, портала и изменения размера.

Быстрый старт​
LIVE EDITOR
function App() {
return (
<Beta.Popover target={<Button text="Открыть" />}>
Контент всплывающего окна
</Beta.Popover>
);
}

Свойство target принимает ReactElement, а содержимое окна передаётся через children.

Примеры​
Trigger / Resizable / Portal

trigger определяет способ открытия: click (по умолчанию), hover или focus.

LIVE EDITOR
function App() {
return (
<div style={{ display: 'flex', gap: '0.5rem' }}>
<Beta.Popover target={<Button text="Click" />}>Открытие по клику</Beta.Popover>
<Beta.Popover trigger="hover" target={<Button text="Hover" />}>Открытие по наведению</Beta.Popover>
<Beta.Popover trigger="focus" target={<Button text="Focus" />}>Открытие по фокусу</Beta.Popover>
</div>
);
}
