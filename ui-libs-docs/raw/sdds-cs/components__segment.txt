Segment (raw sdds-cs — cs-portal re-exports cs-core's own useSegment/SegmentProvider, shadowing this one; see raw/cs-core.json). Wrap in SegmentProvider (defaultSelected=array of value strings, singleSelectedRequired forces one active). Inside, use SegmentGroup > SegmentItem[], and useSegment() -> { selectedSegmentItems }.

SegmentGroup​
Property Type Default Description
view "clear"|"filled"; size "xs"; disabled boolean
pilled boolean; stretch boolean — full width, horizontal only
orientation "vertical" (also horizontal, default)
selectionMode "multiple"|"single" — @deprecated
clip boolean true — scroll + arrow buttons when width constrained
hasBackground boolean; hasDivider boolean
filledBackground boolean — @deprecated use hasBackground
