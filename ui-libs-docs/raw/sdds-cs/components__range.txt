Range — two-field numeric/text range input (firstValue/secondValue), like DatePickerRange but plain text fields. dividerVariant="none"|"dash"|"icon" (+ dividerIcon). firstValueError/secondValueError/...Success/...Edited drive validation styling per-field.

function App() {

}
