Badge (raw sdds-cs version — cs-core's own Badge, re-exported by cs-portal, has a different/stricter discriminated-union API, see raw/cs-core.json "Badge"). size="s". pilled for round corners. view="default"|"accent"|"positive"|"negative" + appearance="default"|"clear" (clear/transparent props are deprecated, use appearance). contentLeft/contentRight for icon slots. customColor/customBackgroundColor for custom colors. Gradient text via class sdds-core-text-node.
