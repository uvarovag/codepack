NumberInput — stepper input with increment/decrement buttons. min/max/step bound the value. precision (default 2) rounds computed step results; decimalScale (default 2) controls displayed decimal digits (independent of precision). isManualInput (default false) allows typing directly, not just arrow buttons/keys. Keyboard: Tab focuses the input only (buttons excluded); ArrowUp/Down step by `step`. displayWithoutValue "input"(default)|"increment"|"decrement" controls what shows when value is empty. limitBehavior "disabled"(default)|"hidden" for buttons at min/max. Shares thousandSeparator/decimalSeparator/thousandsGroupStyle/fixedDecimalScale/allowNegative/allowLeadingZeros/isAllowed formatting props with NumberFormat.
LIVE EDITOR
function App() {
const [value, setValue] = useState(5);
return <NumberInput value={value} min={0} max={10} step={2} width={188} isManualInput onChange={(_, v) => setValue(v)} />;
}
