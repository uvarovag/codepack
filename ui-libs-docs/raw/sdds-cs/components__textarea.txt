Title: TextArea | SDDS CS
URL: https://plasma.sberdevices.ru/sdds-cs/components/textarea/
---
TextArea. appearance="default"|"clear" (hasDivider works with clear). height/width set full component size (number=rem, string=CSS value). rows/cols = fixed absolute size. autoResize (+ minAuto/maxAuto in rows) grows with content. headerSlot for content above the text. clear prop is deprecated legacy mode (ignores rows/cols/height/width/autoResize, height follows content) — use appearance="clear" instead.
LIVE EDITOR
function App() { return <TextArea label="Комментарий" placeholder="Введите значение" autoResize minAuto={3} maxAuto={5} leftHelper="Подсказка" />; }
